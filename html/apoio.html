Este projeto é construído de forma independente, sem investidores e sem mensalidades. Seu apoio ajuda a:

Por que pagamento único?

A filosofia do HUB é simples: você compra uma vez e o software é seu para sempre. Sem mensalidade, sem cobrança recorrente, sem travar suas funções atrás de assinatura.

  • ✓ Sem "preço promocional do primeiro mês" que triplica depois
  • ✓ Atualizações futuras inclusas no mesmo valor
  • ✓ 1 chave ativa até 3 aparelhos — sem custo extra
  • ✓ Suporte pelo WhatsApp incluso

Privacidade em primeiro lugar

Os apps pagos são local-first: todos os seus dados — vendas, clientes, arquivos, vídeos — ficam armazenados no seu próprio aparelho. Nada é enviado para servidores, nada é vendido para terceiros.

  • ✓ Funciona 100% offline (internet só para verificar a chave)
  • ✓ Sem anúncios — você não é o produto
  • ✓ Sem rastreadores ou analytics invasivos
  • ✓ Backup/exportação dos seus próprios dados
