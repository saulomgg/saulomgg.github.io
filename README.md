# Saulomgg Hub

Hub de ferramentas gratuitas · layout cyber · PT (padrão) / EN / ES · apoiado pela comunidade.

## Publicar
Suba esta pasta como um repositório/pasta próprio (ex.: `saulomgg.github.io/hub/`).
NÃO copie por cima da raiz do saulomgg.github.io, senão sobrescreve o seu windows.html, apps.html, sobre.html e comunidade.html atuais.

## Adicionar app (só o arquivo `js/data.js`)
- `APPS`: app no ar (nome, desc, site, app)
- `EM_DEV`: em desenvolvimento (barra de loading). Quando ficar pronto, mova para `APPS`.
- `WINDOWS`: outros programas Windows (além do HubSynk, que fica em `HUBSYNK`)
- `LINKS`: redes, apoio e PIX
Textos aceitam 3 idiomas: `desc:{pt:"",en:"",es:""}`.

## Instalar como app (SHub)
O botão "Instalar" aparece em todas as páginas e como banner na inicial. Precisa estar em HTTPS (GitHub Pages já é).
Ícones em `assets/` (SH). Para trocar o logo, substitua os PNGs mantendo os nomes.

## Banners
`BANNERS` no `js/data.js`. Vazio = "Sua marca aqui" → leva para `apoio.html#marca`.

## Textos das páginas / traduções
Ficam em `js/i18n.js`. O português está direto nos HTMLs.
